# 이나즈마 일레븐 GO 스트라이커즈 2013 한국어 번역 지침

게임: 이나즈마 일레븐 GO 스트라이커즈 2013 (Wii, 레벨파이브). 축구 액션 게임. 등장인물은 이나즈마 일레븐 1~3편과 GO, GO 크로노스톤 시리즈 캐릭터.

## 파일 형식
- 입력: `work/text/in/<배치>.json` = `[{"k": 번호, "src": "일본어"}...]`
- 출력: `work/text/out/<배치>.json` = `{"번호(문자열)": "한국어", ...}` (UTF-8, 모든 k 포함)
- 검사: `python tools/py/check.py <배치>` (작업 폴더 `D:\wii\이나즈마일레븐Go_스트라이커2013` 에서 실행). 오류 0건이 될 때까지 수정.
- 번역은 반드시 직접 한다. 외부 번역기/API 사용 금지.

## 제어 코드 (절대 변경 금지)
- `#`로 시작하는 명령은 그대로 유지: `#P10#=`, `#C#=`, `#C`, `#I1#=`, `#I0`, `#n`(줄바꿈), `#b84#=`(버튼 아이콘), `#z80`(크기), `#oy3`, `#x15#=`(자간), `#Rx9`, `#Rm-3`, `#Re1#=`, `#W`, `#j`, `#Q2`, `#Y17`, `#U96`, `#y4` 등.
- `%s`, `%d`, `%2d` 등 서식 지정자 유지.
- 실제 줄바꿈(\n)과 `#n`의 개수는 원문보다 늘리지 않는다(줄 수 ≤ 원문).
- 색 지정 `#P10#=키즈나#C#=` 처럼 강조 대상 단어를 감싼 코드는 대응하는 한국어 단어를 감싸도록 위치를 옮겨도 된다(코드 종류와 개수는 동일).
- 원문의 루비(후리가나)는 이미 제거되어 있다.

## 글자 제약
- 한글은 KS X 1001 완성형 2350자만 사용 가능(검사기가 알려줌). 안 되는 글자는 다른 표현으로.
- 사용 가능한 기호: 일본어 전각 문장부호 `！？。、…「」『』（）・～ー：＆％＋－×` 와 ASCII 문자. 한국어 문장에서는 `！ ？` 대신 ASCII `! ?`, 마침표 `.`, 쉼표 `,` 사용을 권장(폭이 좁음). 말줄임표는 `…`.
- 띄어쓰기는 ASCII 공백(반각). 전각 공백 `　`은 원문에 정렬용으로 있을 때만 유지.
- 숫자: 원문이 전각 숫자면 전각 유지 가능.
- 가나·한자 잔존 금지.

## 길이 제약
- 한글 1자 = 폭 2, ASCII(공백 포함) = 폭 1. 각 줄 폭이 원문 최대 줄 폭을 넘으면 안 된다(검사기 확인). 메뉴/버튼은 특히 짧게.

## 문체
- 대사는 캐릭터 말투 살리기: 텐마(밝은 존댓말/반말 섞인 소년), 아오이·아키(마네저: 친근한 반말/해요체), 감독(엔도: 열혈 반말), 츠루기(무뚝뚝 반말), 신도(정중한 반말) 등. 원문 어조(です/ます→해요/합니다, だ/よ→반말)를 따른다.
- 시스템 메시지: "~하시겠습니까?", "~합니다." 형태의 간결한 존댓말.
- 설명문(아이템·필살기·캐릭터 설명): "~한다", "~하는 기술!" 등 원문 톤에 맞춘 간결체.

## 고유명사 규칙
- 일본 인명은 일본어 발음을 한글로 표기(성 이름 순). つ→츠, 장음 생략(원도 마모루X → 엔도 마모루). 예: 円堂守=엔도 마모루, 松風天馬=마츠카제 텐마, 剣城京介=츠루기 쿄스케, 神童拓人=신도 타쿠토, 霧野蘭丸=키리노 란마루, 豪炎寺修也=고엔지 슈야, 鬼道有人=키도 유토, 風丸一郎太=카제마루 이치로타, 西園信助=니시조노 신스케, 空野葵=소라노 아오이, 雷門=라이몬, 帝国学園=제국학원, 円堂大介=엔도 다이스케.
- 히라가나 단축명(しんどう 등)은 한글 성/이름 표기(신도).
- 가타카나 외래어 이름/필살기는 원어를 살린 외래어 표기: ファイアトルネード=파이어 토네이도, ゴッドハンド=갓 핸드, マジン・ザ・ハンド=마진 더 핸드, イナズマイレブン=이나즈마 일레븐, キズナ=키즈나(게임 시스템 용어, 유지), ミキシマックス=믹시맥스, ケシン(化身)=화신, ＴＰ=TP 유지.
- 일본어 고유어 필살기(さばきのてっつい 등)는 뜻을 살려 번역(심판의 철퇴).
- 용어집(`work/text/glossary.json`)이 있으면 반드시 따른다.
